# 网易云账号模块 1.1.3

源码：`modules/music-wangyiyun.js`。这是独立编写的账号版，未复制或修改下载文件中的加密实现。使用 Rex / ForwardWidget 的 HTTP、存储、列表、详情和播放资源接口。

## 导入与登录

1. 在 Rex 的 JavaScript 模块导入入口选择 `music-wangyiyun.js`，或用发布链接 `https://raw.githubusercontent.com/zt001110/rex-modules/main/encrypted/modules/music-wangyiyun.js` 导入。
2. 在电脑浏览器打开 `https://music.163.com` 并登录自己的账号。
3. 打开浏览器开发者工具的 Network / 网络面板，刷新页面。在发往 `music.163.com` 的已登录请求中，找到 Request Headers / 请求头的 `Cookie`，复制该请求头的完整值。应包含 `MUSIC_U=...`，可同时包含 `__csrf`、`NMTID` 等字段。不要复制 `Set-Cookie` 响应头或整段 curl 命令。
4. 在 Rex 本模块的全局参数“网易云 Cookie（可只填 MUSIC_U 值）”中，直接粘贴 `MUSIC_U` 这一行右侧的 Cookie Value，模块会自动补上 `MUSIC_U=`。也可以填完整的 Cookie 请求头。音质先选“标准”。
5. 打开“账号状态”，确认显示自己的昵称，再打开“我的歌单”“我喜欢的音乐”或“私人 FM”。

Cookie 只作为请求头发送到 `https://music.163.com/api/`，不会发送给音频 CDN、二维码服务或第三方 API，也不会写进条目链接。不要把含 Cookie 的参数截图、日志或模块配置公开分享。Rex 的参数保存方式及系统备份由客户端决定，模块无法提供系统钥匙串级的存储保证。

模块为不接收全局参数的 `loadDetail(link)` 在 `Widget.storage` 留存一份 Cookie 和音质。首次进入账号或列表后才具备详情登录态；更换账号后先打开“账号状态”，并刷新旧列表。清除登录时，同时清空全局 Cookie 参数并运行“账号状态 → 清除本模块登录缓存”，否则后续调用仍会用参数重新保存。此操作不会退出网易云网页或撤销服务器会话。

## 功能与边界

- 每日推荐：读取账号的每日推荐歌曲，生成带分集的播放队列；由网易云决定歌曲数量及当日推荐内容。
- 推荐歌单：读取账号的推荐歌单，点开沿用普通歌单详情、分页和连播。
- 漫游 / 私人 FM：支持默认、熟悉、探索和场景模式。场景支持放松、专注、运动、助眠、治愈、欢快、通勤、轻音乐、国风和经典。使用 `/api/v1/radio/get` 的模式参数，实测每批 3 首；刷新入口获取下一批，不实现原生 App 的无限续补及播放反馈，也不保证与原生 App 当时的推荐完全一致。
- 心动模式：使用网易云智能播放接口。默认查找本账号的“我喜欢的音乐”，以歌单第一首为种子；也可指定歌单及其中的种子歌曲。打开或刷新模块入口时重新请求推荐，不按午夜或 24 小时定时更新。每次替换同一个 `ncm:heart` 条目的歌曲，继续观看与下方心动入口读取同一份当前列表。完整列表在同一详情展示，元数据及播放地址仍按每批 100 首获取，避免分页产生其他历史条目。不修改收藏或喜欢状态。
- 热歌榜：读取排行榜目录中各类热歌榜。
- 我的歌单：读取账号创建及收藏的歌单，每页 30 个。
- 我喜欢的音乐：读取喜欢的歌曲 ID，按接口顺序每页 100 首，不按免费标签过滤会员歌曲。
- 歌单详情：每批 100 首，详情的相关条目提供上一页、下一页。“打开歌单”也可输入数字歌单 ID 后翻页。
- 私人 FM：读取 `/api/v1/radio/get` 当前返回的推荐批次，刷新重新请求。这个接口对应私人 FM，尚未核实与现版网易云 App“私人漫游”的推荐完全一致；不实现播放反馈、自动续补、红心或垃圾桶操作。
- 搜索：每页 30 首，可包含账号没有播放权限的歌曲。
- 播放：按当前 Cookie 和所选音质重新取地址，匹配返回的歌曲 ID。缺少版权或会员权限、仅返回试听时明确报错。不解锁付费内容，不使用替代歌曲。取源请求补齐 `os=pc`，避免仅填 MUSIC_U 时返回不可用的签名地址；不改动保存的 Cookie。音频地址使用 HTTPS，携带网易云 Referer / User-Agent，不向音频 CDN 发送 Cookie。
- 歌单详情用一次批量请求为当前页可完整播放的分集填写 `videoUrl` 和播放请求头，兼容 Rex 播放器内切集时的详情解析；歌曲详情也携带播放地址。缺少权限或仅可试听的分集保留展示，但不填播放地址。详情缓存为 0，重新加载详情时更新签名地址；`loadResource` 仍按当前歌曲重新取源。长时间停留后出现过期地址时需重新打开歌单。

推荐队列保存歌曲 ID 顺序，切集时只更新元数据和音频签名，不重新运行推荐算法。每日推荐与漫游队列保存在本模块存储中，绑定账号 UID，有效期 24 小时，最多保留最近 12 个；更换账号后不能打开旧账号的队列。清除本模块登录缓存会一并删除推荐队列。更新模块后，返回资源库重新进入本模块查看新增入口。

心动模式单独保存当前列表，绑定账号 UID，不被漫游队列轮换挤掉。刷新失败保留上一份可用列表；详情重载或播放器切集不会触发重新推荐。1.1.3 起，分集也使用固定的位置链接 `ncm:heart:1`、`ncm:heart:2` 等，元数据和起播均按当前列表的位置解析，不再把会变化的歌曲 ID 作为心动分集身份。旧版队列和午夜缓存中仍能识别的心动链接会登记为别名，打开时返回当前心动列表；无法识别归属的过期队列不会猜测成心动模式。Rex 已有的历史记录由客户端管理，模块没有批量删除历史的接口，旧重复卡片需要在客户端移除一次。旧记录如果仍保存旧歌曲分集对象，需要从新版心动入口播放一次，以建立固定分集的续播记录。固定身份用于阻止后续每次刷新产生不同的心动条目，模块无法强制刷新 Rex 当前页面已缓存的封面或历史数据。网易云可能返回相同歌曲，重新请求不保证内容不同。

账号模块依赖网易云未公开承诺兼容性的网页 API。登录风控、地区、账号权限和接口变动都可能影响结果；当前未实现 weapi / eapi 加密请求或备用服务器。HTTP 200 和匿名查询成功不代表账号接口在所有账号上可用。

## 验证

```sh
node --check modules/music-wangyiyun.js
node test-netease-account.cjs
```

2026-11-08：离线测试已通过，覆盖 Cookie / CSRF 请求、喜欢歌曲的顺序、超过 100 首的歌单翻页、私人 FM、搜索、即时取源、试听拒绝、过期登录与外部条目不出源。同一份模块的真实匿名接口调用返回搜索 30 首、歌曲详情、热歌榜第二页 100 首及私人 FM 数据；未登录账号返回空 profile。匿名请求会员歌曲未取得地址并按预期报错，公开可听歌曲取得地址，CDN 范围请求返回 `206 audio/mpeg`。这些结果仅确认接口和音频请求，不代表 Rex 播放器实播通过。
